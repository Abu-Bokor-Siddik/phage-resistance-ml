# Machine Learning for Predicting Phage Resistance Persistence

## Project Overview

An exploratory machine learning project investigating the relationship between bacterial phage resistance fitness costs and simulated population persistence.

## Research Question

Can a machine learning model identify patterns associated with simulated phage resistance persistence using computational features?

## Dataset

A synthetic dataset containing 1,000 observations and three input features:

- Fitness Cost
- Relative Growth
- Simulated Phage Pressure

Target variable: Persistence (0 or 1).

The target labels were generated using a predefined mathematical rule with random noise.

## Model

Random Forest Classifier using Scikit-learn.

- 100 decision trees
- Maximum tree depth: 5
- Training data: 80%
- Testing data: 20%

## Evaluation

The model was evaluated using:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

## Limitations

The dataset is entirely synthetic. The model learns patterns generated by predefined assumptions and does not establish real-world biological relationships or clinical predictions.
